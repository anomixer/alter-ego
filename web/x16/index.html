What this is, the controls, and the notices

What you are running

The real Commander X16 binary from this repository's x16/spike/dist/ — the same LOADER.PRG, GAME, MUSIC and 26 level files you would put on an SD card — loaded into the emulator's virtual drive and started with -prg loader.prg -run. The emulator is the official X16Community WebAssembly release r49, fetched and checksum-checked when this site is built; it is not vendored in the repository.

Controls (keyboard)

KeysAction
Arrow keysMove, climb ladders, and highlight menu rows
Z / XExchange with your shadow (A / B on a pad)
Enter / SpaceStart, confirm, pause
1 / Left ShiftSelect (title menu: jump to the cow level)
T / EscSFX/BGM test screen
M / NMusic mute / sound-effects mute

A USB gamepad works too (A = exchange, B = the other exchange button, Start = Enter, Select = 1). The emulator keeps the X16 keyboard layout (en-us), so physical key positions are what the KERNAL sees.

Notes

Audio starts muted; use the “Sound” button (browsers require a click before they allow sound). “Fullscreen” scales the 640×480 VERA screen; “Restart” reloads the page and boots the X16 again. On slower machines the first boot takes a few seconds while the 38 game files are copied into the emulator's memory.
